# Como revisar o protótipo

Abra `alva-studio-ui-reference.html` ou `alva-studio-analytics-tracking-reference.html` no navegador. Os dois arquivos são referências visuais locais: não conectam domínio, publicam conteúdo, enviam convites nem gravam dados em servidor.

Navegue normalmente para abrir as telas disponíveis. Passe o mouse ou use Tab em um controle para ver sua finalidade e o resultado esperado do clique. Ações que ainda não têm produto conectado mostram uma explicação clara, incluindo os dados que seriam necessários.

Use **Modo de revisão** para transformar um texto, card ou botão em proposta. A revisão não executa a ação do controle. Preencha o nome, finalidade, resultado esperado, dados necessários e notas; a proposta permanece com o estado **Proposta · aguardando análise**.

As propostas ficam no armazenamento local do navegador. Use **Exportar JSON** para guardar ou levar propostas a outro computador e **Importar** para recuperá-las. Se o armazenamento local falhar, a barra informa que a proposta ficou apenas na sessão e recomenda exportar o JSON.
